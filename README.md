# Mohammed Rihab & Tafzeena — Nikkah Invitation

Next.js App Router invitation site with Tailwind CSS, Framer Motion, Three.js scroll-driven wedding rings, Lucide icons, and the supplied nasheed at `public/nasheed.mp3`.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
